# Segurança

Para reportar uma vulnerabilidade, use "Report a vulnerability" na aba Security deste repositório (aviso privado).
Não abra issue pública com detalhes de falha.

Este repositório não deve conter segredos, chaves, dados financeiros reais nem identificadores da infraestrutura
(conta, instância, bucket). Os valores reais ficam no AWS Systems Manager e nas variáveis do Environment do GitHub.
