# `src/app/common/components`

Componentes de base do moneylog (UI própria, ADR-007). **Nenhum controle nativo** do navegador
(`<select>`, `<input type=date|month|checkbox|...>`, `<details>`, `<dialog>`, `title`, `alert/confirm/prompt`):
a guarda `npm run lint` (`scripts/check-native-controls.mjs`) e o E2E `e2e/native-controls.e2e.ts` falham se um
aparecer. Todos têm `data-cy`, rótulo acessível e seguem os tokens (`src/styles/tokens.css`). Para ver cada
componente em todos os estados e nos dois temas: `/dev/ui-kit` (só em `npm start`/`npm run start:mock`).

Regra geral dos campos de formulário: ligue com `[formControl]` ou `formControlName`, passe `label` (nome acessível,
visível) e `fieldId` (vira o `data-cy` e a base dos ids). O erro aparece depois que o campo foi tocado.

| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |

Máscara por idioma (dd/mm/aaaa ou mm/dd/yyyy), calendário, "Hoje/Ontem". `mandatory=false` permite limpar.                                                                                                          | `YYYY-MM-DD \| null` |

| `app-text-field`        | Texto livre (`text`, `email`, `password`). Nunca outro tipo.                                                                                                                                                                                               | `string`             |
| `app-money-input`       | Valor em dinheiro, com a moeda do dado (não a do idioma). A API calcula; o campo só digita.                                                                                                                                                                | `string` decimal     |
| `app-segmented-control` | Poucas opções (2 a 4) sempre visíveis (tipo da movimentação, visão). Mais que isso, use `app-select`.                                                                                                                                                      | `string \| null`     |
| `app-radio-group`       | Escolha única com **descrição** por opção ("Fatura total: paga tudo de uma vez"); `layout` `vertical`, `horizontal` ou `cards`. Setas movem e marcam (APG).                                                                                                | `string \| null`     |
| `app-number-stepper`    | **Inteiros** pequenos (nº de parcelas 1 a 36, dia do mês 1 a 31). `min`/`max`/`step`, `valueText` ("6 parcelas"). Nunca dinheiro (use `app-money-input`).                                                                                                  | `number \| null`     |
| `app-checkbox`          | Marcar/desmarcar um fato ("só estornadas").                                                                                                                                                                                                                | `boolean`            |

## Sobreposições e estrutura

| Componente                                 | Quando usar                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app-overlay-panel` (`overlay/`)           | Base de Select, calendário e meses: popover ancorado (> 640 px) ou folha inferior modal (até 640 px). Use só para criar um campo novo; para o resto, use os componentes acima. `Esc` e toque fora pedem o fechamento (`closed`); quem usa controla `open`.                                                                                                |
| `app-dialog`                               | Diálogo modal composto sobre o `OverlayPanel` (`mode="modal"`): `role` `dialog`/`alertdialog`, `layout` (`responsive-center` padrão, `center`, `bottom`, `side`), `dismissable=false` para exigir resposta, foco inicial em `data-autofocus`.                                                                                                             |
| `app-sheet`                                | Folha inferior até 640 px (cantos de 18 px, até 90 `dvh`, rolagem interna) e painel central ou lateral (`desktop`) acima. É um `Dialog`.                                                                                                                                                                                                                  |
| `app-menu`                                 | Menu de ações (`aria-haspopup="menu"`): `items` com `disabled`, `destructive` ou `checked` (checkbox); `selected` emite o `id` depois de devolver o foco ao botão. Até 640 px abre como folha.                                                                                                                                                            |
| `app-tabs` + `appTabPanel`                 | Abas com ativação automática (`[(active)]`, ligável a `?tab=`); painéis em `<ng-template appTabPanel="id">` (montados na 1ª abertura). Rola na horizontal com sombra nas bordas.                                                                                                                                                                          |
| `app-progress-bar`                         | Razão 0..1 **do backend** (`value`; `null` = indeterminado) com `valueText` formatado por quem usa; `warning`/`risk` sempre com texto. Nunca `<progress>`/`<meter>`.                                                                                                                                                                                      |
| `app-confirm-dialog`                       | (sobre o `Dialog`, mesma API e `data-cy`) Confirmar uma ação que muda estado (arquivar, estornar). `requireReason` pede um motivo; `tone="risk"` para ações que mudam saldo; `busy` evita envio duplicado.                                                                                                                                                |
| `app-disclosure`                           | Seção que recolhe (filtros no celular, "arquivadas"). `[(open)]`; o botão fica num `heading` (`headingLevel`, padrão 2); a região é um landmark (`heading` único na página).                                                                                                                                                                              |
| `appTooltip` (diretiva)                    | Dica curta de um botão ou ícone ("Disponível em breve"). Nunca o atributo `title`. Em botão desabilitado, use `aria-disabled` para ele continuar focável.                                                                                                                                                                                                 |
| `app-toast-region` / `ToastService`        | Aviso curto depois de uma ação. Montado uma vez no shell.                                                                                                                                                                                                                                                                                                 |
| `app-empty-state` / `app-error-state`      | Estados de tela: vazio (com ação) e erro (com "Tentar de novo").                                                                                                                                                                                                                                                                                          |
| `app-page-layout`, `app-section-container` | Esqueleto da página (`<main>` e único `<h1>`) e seção com título.                                                                                                                                                                                                                                                                                         |
| `app-chip`                                 | Pílula de rótulo: **alternável** (`pressed`, `button aria-pressed`: filtro por tag), **removível** (`removeLabel`, com o nome acessível do botão) ou **estática** (tag da nota). `count` opcional em números tabulares.                                                                                                                                   |
| `app-workspace-header`                     | Cabeçalho do shell (DS 02): saudação **sem nome** só no Início ("Bom dia/Boa tarde/Boa noite", pela hora do aparelho, FE-S-211), ações rápidas (`/quick-add?mode=`), "Perguntar à IA" **desabilitado**, chip "IA desligada" e o menu do perfil no mobile. Sem sino (Etapa 7).                                                                             |
| `app-profile-menu`                         | Avatar genérico + `Menu` (Configurações, Sair). No rodapé da sidebar e, no mobile, no cabeçalho. Sem seletor de workspace nem nome (D4).                                                                                                                                                                                                                  |
| `app-line-chart`                           | Gráfico de linhas/área em **SVG próprio** (`series: Money`, `keys`): curva monotônica, eixo Y só com o máximo da série e o zero, tooltip por mouse, toque e teclado (`←/→`, `Home/End`, `Esc`), região viva, **tabela equivalente sempre no DOM**, entrada na viewport. Estado vazio honesto. `income-expense-chart.mapper.ts` adapta a série do backend. |
| `app-bar-list`                             | Barras horizontais de categoria: lista semântica com valor e `share` (formatado, nunca calculado) em texto e barra `aria-hidden`; "Outras (N categorias)" por último; negativo em tom de risco.                                                                                                                                                           |
| `app-segmented-bar`                        | Barra segmentada com segmentos **já calculados** pelo backend e legenda em texto; estado `disabled` ("Disponível em breve", sem número). Para o orçamento mensal futuro.                                                                                                                                                                                  |
| `app-money`, `app-icon`                    | Valor monetário com a moeda do dado; ícones do conjunto próprio.                                                                                                                                                                                                                                                                                          |

## Utilitários de overlay (`overlay/`)

`ViewportService` (compacto <= 640 px), `lockModal` (trava de rolagem + fundo `inert`; marque regiões que devem
continuar acessíveis com `data-modal-safe`), `LiveAnnouncer` (anúncios para leitor de tela, dentro do modal aberto),
`computePosition` (flip e shift), `focusReturnTarget` (para onde o foco volta; o Safari não foca botão no clique),
`focus-trap` (`focusableElements` e `trapTab`: o foco preso de qualquer modal).

`Dialog`, `Sheet` e `Menu` **não são um segundo primitivo**: compõem o `OverlayPanel` (`mode="modal"` + `layout`, ou
`mode="auto"` no Menu), então herdam a pilha de `Esc`, `inert` no fundo, trava de rolagem e devolução de foco.

## Camadas (z-index)

Diálogo (`Dialog`/`Sheet`/`ConfirmDialog`) 50, popover e folha dos campos 60, tooltip 70, aviso 80 (`--z-*` em
`tokens.css`). Um `Select` aberto dentro de um diálogo fica por cima dele.

## Acrescentar um controle novo

1. Crie o componente aqui, com `FieldControl` (rótulo, ids, erro) e `OverlayPanel` se abrir algo.
2. Teste: comportamento (Testing Library), teclado, axe e o caso `Tab`/`Esc`.
3. Mostre-o em `/dev/ui-kit` (`features/dev/ui-kit`) em todos os estados.
4. Se for um tipo que o navegador desenha sozinho (arquivo, hora), **nunca** use o nativo: crie o componente próprio.
